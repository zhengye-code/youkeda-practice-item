# RAG、Skill 与 Function Calling

RAG 是检索增强生成。它先从外部知识库检索与问题相关的片段，再把片段连同用户问题交给大模型，使回答有资料依据。最小流程包括准备文档、切分片段、检索 Top K、拼接上下文、让大模型基于上下文回答并标注来源。

Skill 是可复用的业务流程和验收规则，解决“遇到这类任务应按什么步骤做”。例如学习复盘 Skill 可以固定为：概念、实际产出、测试证据、问题风险、下一步行动。

Function Calling 解决“调用哪个代码工具执行动作”。天气查询、获取时间和计算器都是原子工具。Skill 可以编排流程，Function Calling 执行动作，RAG 提供知识依据，三者职责不同但可以组合。

只有普通工具时，模型能执行预先注册的原子动作，但不一定知道项目私有资料，也没有稳定的多步骤业务流程。加入 Skill 后，命中业务关键词即可执行固定流程；加入 RAG 后，知识类问题可以先查本地资料，再生成有来源的回答。
