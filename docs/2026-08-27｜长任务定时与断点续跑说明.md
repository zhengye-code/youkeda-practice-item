# 校园 AI 学习助手｜长任务定时与断点续跑

## 本次目标

在已有结构化学习内容生成模块上，补充适合课程演示的长任务能力：用户只提交最终目标，系统自动拆分步骤，可预约执行，并在中断后从最近检查点继续。

## 执行流程

```text
创建高层目标
  → 检查点1：解析目标与约束
  → 检查点2：调用 LearningContentService 生成 Markdown
  → 检查点3：整理最终成品
  → COMPLETED
```

任务状态包括 `SCHEDULED`、`RUNNING`、`PAUSED`、`COMPLETED` 和 `FAILED`。步骤状态包括 `PENDING`、`RUNNING`、`COMPLETED` 和 `FAILED`。

## 定时任务

- Spring `@Scheduled` 默认每 1000 毫秒扫描一次到期任务；
- 到期任务提交到 Java 21 虚拟线程，调度扫描不等待大模型返回；
- `runningTaskIds` 对同一个任务 ID 去重，避免重复调度；
- 支持创建时指定 ISO-8601 UTC 时间，也支持通过 `/run` 立即执行。

## 断点续跑

- 每一步开始、成功或失败时都会更新任务 JSON；
- 使用临时文件加原子移动，避免写到一半留下损坏检查点；
- 步骤失败时保留 `nextStepIndex`，恢复后从失败步骤继续；
- 应用重启发现 `RUNNING` 任务时，将当前步骤重置为 `PENDING` 并重新调度，已完成步骤不会重复执行。

## 性能与 token 优化

1. 虚拟线程：慢速 LLM 请求不占住调度线程。
2. Prompt 字符预算：历史上下文默认限制在 6000 字符内，优先保留最近对话和当前请求。
3. 上下文窗口：默认只保留最近 4 轮。
4. 重复请求复用：同一会话、同一意图连续发送完全相同的请求时，直接返回上一轮结果，不再次调用大模型。
5. 调度去重：同一长任务不会并发执行两次。
6. 请求超时：结构化生成和工具调用请求设置 60 秒上限，超时后保存失败检查点，可从该步骤恢复。

## 验收边界

离线测试可以验证任务拆分、定时扫描、检查点持久化、失败续跑、重启恢复、Prompt 预算和重复请求复用。真实百炼 API 的响应时间与 token 用量仍需配置有效 API Key 后通过平台用量记录验收。
